Open the tool in your browser. 2. Click the "Search Water" box. 3. Type a river or lake name. Examples: "South Platte", "Arkansas", "Gunnison", "Blue River". 4. Click the result that matches your location. 5. The tool shows a list of recommended fly patterns for that water. ### Filtering by Fish Species 1. Click the "Species" dropdown menu. 2. Select "Rainbow Trout", "Brown Trout", "Brook Trout", "Cutthroat Trout", "Smallmouth Bass", "Largemouth Bass", "Northern Pike", or "Kokanee Salmon". 3. The tool updates the list to show only flies that work for that fish. ### Using the Season Filter 1. Click the "Season" dropdown menu. 2. Choose "Spring", "Summer", "Fall", or "Winter". 3. The tool shows flies that match the current season. ### Viewing Fly Details 1. Click any fly pattern name in the list. 2. A panel opens with information about the fly. You see its size, color, hook type, and when to use it. 3. Click the "Close" button to return to the main list. ## 🛠️ Installing the Offline Version The offline version lets you use the tool without internet access.
